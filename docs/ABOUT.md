## What it is

A hand-crafted marketing and product showcase site for QuickDictate, a Windows tray app for speech-to-text. Single HTML file with no build process, deployed on GitHub Pages. Explains the app's capabilities (cloud or offline models), unique positioning (no subscription, free, MIT-licensed), and links to downloads and source.

## Things not to forget

_The intricacies worth remembering: the gotchas, the half-built parts, the decisions whose
reason lives nowhere else. Odin never overwrites this section._

- The app version (e.g. v0.8.0) is hardcoded in three separate places - the JSON-LD schema, the hero eyebrow text, and the final CTA copy - with no automation tying them together, so every app release requires a manual find-and-replace across all three or the site silently goes stale. anchors: `index.html:701`
- Several real, deployed pages (pricing.md, llms.txt, llms-full.txt, CHANGELOG.md, sitemap.xml) have no link anywhere in the nav or footer, so they're reachable only by a direct URL or a crawler, not by clicking around the site. anchors: `index.html:165`
- There is no build process at all: index.html is a single hand-written file with inline CSS and no package.json, so changes are made directly in the file and verified by opening it in a browser before pushing to main. anchors: `index.html:1`
- The privacy section's claims (no telemetry, no account, nothing sent to LunarWerx when using offline models or the visitor's own cloud API keys) are a deliberate positioning decision baked into the copy, not just a feature description, so it shouldn't be loosened or genericized in a rewrite. anchors: `index.html:1095`
- The site keeps its own CHANGELOG.md tracking edits to the landing page itself, which is a completely separate document from the QuickDictate app's own changelog in the app's repo - easy to update the wrong one. anchors: `CHANGELOG.md:1`
- The social share card (assets/og-image.png) is not generated by any script - it's produced by manually rendering tools/og-card.html at exactly 1200x630 with headless Chrome and overwriting the PNG, so it will quietly drift out of date after any rebrand unless someone remembers this step. anchors: `tools/og-card.html:6`
- SEO structured data (SoftwareApplication, Organization, WebSite, BreadcrumbList, FAQPage JSON-LD) lives in the document head and duplicates facts already stated in the visible copy (version, description), so editing the page text without also updating the JSON-LD lets the two silently disagree. anchors: `index.html:690`
